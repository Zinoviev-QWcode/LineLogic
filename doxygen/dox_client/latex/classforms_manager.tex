\doxysubsection{Detailed Description}
The \doxylink{classforms_manager}{forms\+Manager} class manages the application\textquotesingle{}s window transitions. 

This class handles the creation and management of all application windows and the transitions between them (authentication, queue hub, queue creator, etc.).
